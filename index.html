About this project

AyurClassify

AyurClassify is a TYCS educational project that demonstrates how selected Ayurvedic concepts can be represented using a simple rule-based classification system. It collects questionnaire answers, calculates category scores using predefined rules and saves results for the signed-in user.

FrontendHTML, CSS and JavaScript
BackendNode.js and Express API
DatabaseMySQL
Core conceptRule-based scoring

This is a simplified learning model, not a medical diagnostic tool.
